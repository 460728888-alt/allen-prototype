# Allen 个人机会研究台

网址：https://460728888-alt.github.io/allen-prototype/

网页可以公开访问。个人股票池、持仓、笔记和独立研究只保存在当前浏览器，不上传GitHub、不连接Render或原数据库。清除网站数据、换浏览器或存储故障时不能承诺恢复，请在“股票池与跟踪”导出备份。导入只合并，原判断/持仓冲突会拒绝整批导入，不静默覆盖。

## 功能

今日机会、机会演化、个股研究档案、可点击的日期/公式/来源解释、本地原始判断与追加记录、同股多次研究、股票池、持仓、费用计算、备份和简报。公司基础字段、财务、行业、公告雷达、AI研究、原趋势与风险入口均保留并标记可用性。完整财报、行业比较、自动公告及安全AI服务尚未接入，不编造数据或把规则文字冒充AI。

## 数据与限制

GitHub Actions工作日收盘后读取公开行情生成静态文件，不是实时后台。“读取最新数据”只重读已发布文件。区分目标1200、实际池、请求、返回、可判断、失败、过期、不足和未请求；备用32只样本不冒充全市场。全失败明确无法完成判断，缺失不补0，日历过期或资料落后时暂停。官方日历目前覆盖至2026-12-31。

统一沿用AllenPt1已审阅的20日结构公式；T1＋1.5仍为配置不兼容，合格候选未判定，T2未启用，不训练或启用模型。结构与历史上涨比例不是当前上涨概率，不承诺一周必涨。风险预算待设置，不生成个人仓位建议、不自动下单；跳空、跌停、停牌、T+1及流动性可能影响实际成交。

原始研究保存真实创建时间、数据截止、策略版本、关键价位及证据；之后只追加。没有当时保存的判断，不事后冒认预测。公司行动导致原价不可比时暂停，缺失数据不判失效。
