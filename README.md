# Allen 个人机会研究台

网址：https://460728888-alt.github.io/allen-prototype/

网页可以公开访问。个人股票池、持仓、笔记和独立研究只保存在当前浏览器，不上传GitHub、不连接Render或原数据库。清除网站数据、换浏览器或存储故障时不能承诺恢复，请在“股票池与跟踪”导出备份。导入只合并，原判断/持仓冲突会拒绝整批导入，不静默覆盖。

## 功能

今日机会、机会演化、个股研究档案、可点击的日期/公式/来源解释、本地原始判断与追加记录、同股多次研究、股票池、持仓、费用计算、备份和简报。公司基础字段、财务、行业、公告雷达、AI研究、原趋势与风险入口均保留并标记可用性。公开公司概况、财报关键值和公告索引已接入，各自显示来源与覆盖限制。完整财务分析、行业比较和安全AI服务尚未接入，不把标题当已读正文，不把规则文字冒充AI。

## 数据与限制

GitHub Actions工作日收盘后读取公开行情生成静态文件，不是实时后台。“读取最新数据”只重读已发布文件。区分目标1200、实际池、请求、返回、可判断、失败、过期、不足和未请求；备用32只样本不冒充全市场。全失败明确无法完成判断，缺失不补0，日历过期或资料落后时暂停。官方日历目前覆盖至2026-12-31。

统一沿用AllenPt1已审阅的20日结构公式；T1＋1.5仍为配置不兼容，合格候选未判定，T2未启用，不训练或启用模型。结构与历史上涨比例不是当前上涨概率，不承诺一周必涨。风险预算待设置，不生成个人仓位建议、不自动下单；跳空、跌停、停牌、T+1及流动性可能影响实际成交。

原始研究保存真实创建时间、数据截止、策略版本、关键价位及证据；之后只追加。没有当时保存的判断，不事后冒认预测。公司行动导致原价不可比时暂停，缺失数据不判失效。

## 公司资料与原始留档

公司资料、财报和公告与行情分别取得和计数，不是实时公告服务。财务仅展示已取得的报告期关键值，营收和利润为来源累计口径，非单季，不直接计算TTM。百分数按来源原值；金额单位来自源表头元，币种缺失不默认CNY。公司概况允许7日缓存且保留原获取时间；公告只取最近日期范围内有限分页，并公开未覆盖部分。

披露日期、修订日期与本系统实际见到的时间分别保留；只有日期不足以证明盘中已知。新研究在保存时复制当时已加载的资料版本，旧研究没有保存的资料不事后补入。后来资料可明确追加为笔记快照，原始记录不覆盖。只在完整行情档案加载并通过校验后建立新研究。

公司概况首次获取预算为75秒，优先原网站公开固定样本，再按代码继续获取其余名单；这是资料请求顺序，不是推荐排名，也不缩减行情或财报的1,200只目标。未请求、超时及缓存分别公开，后续更新可复用7日内已成功资料。
