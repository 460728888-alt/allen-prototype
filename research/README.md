# 隔离五交易日开发训练实验

本目录只在 research/five-session-development-v1 分支的独立 Actions 中运行。contents:read；不保存仓库写权限，不写数据库，不发布模型，不开启付费服务。上线网页不读取本目录的模型或研究概率。

## 冻结目标和样本
- 判断日已完成日线之后，下一交易日开盘到第五交易日收盘的原始价格是否上涨（未扣费）。
- 固定当前32只A股，2024-2025真实提供方历史日线；不是无偏历史股票池，也不是当时留存的预测。
- 2024-08-30及以前用于训练，2024-09-09至12-31校准，2025-01-09至12-31开发验证。各段未来标签不得越过段尾；段间留间隔。
- 2025已经参与过研究，只能称开发验证，2026不请求、不读取、不评估。
- 61根已完成交易日计算10项冻结特征；ret60需要61个收盘。缺价格、量、因子、交易日直接排除，不补零。
- 特征价格按判断日因子锚定；历史quote尺度仍未经独立核验。特征窗口拆股和标签窗口任何公司行动均排除并记录。

## 比较和限制
日期内股票等权，再对日期等权。训练集常数概率和简单趋势规则作为基线，固定小参数逻辑回归、LightGBM、CatBoost作候选；不搜索参数，不根据2025调阈值、不选择胜者。2024校准集单独拟合sigmoid，不在开发集拟合。

报告方向分类、Brier、logloss、AUC、可靠性分箱、固定0.6阈值的信号/无信号比例、同日基准、0/30/60基点对称比例费用假设、季度表现。0.6不是上线资格或正式筛选策略。上涨标签不混为扣费盈利概率。

股票日及五日窗口重叠。成本情景不能证明真实成交，跳空、停牌、涨跌停、最低佣金、税率及资金约束未建模；实际交易收益、组合最大回撤、先止盈概率均未研究，保留null。不承诺一周必涨或超过其他网站。个人风险额度未设置，不生成仓位建议。正式T1/RR配置继续不兼容、合格候选未判定、T2不启用。

## 运行与产物
Actions的 Isolated five-session model development 在本分支 research/** 或该工作流发生变更时运行：
1. 固定依赖及单元/隔离测试。
2. 请求前存协议和日历，下载原始JSON并保存每次请求的结果和哈希。
3. 清洗数据、排除原因、分割台账；训练模型并保存全部开发集预测。
4. 即使失败也上传日志及已有原数据。SHA256SUMS可核对全部实验数据和产物；源码由Actions的提交版本固定。
5. artifact名含运行编号和尝试次数，临时保留90天，**不是永久备份**。到期前从对应Actions运行底部Artifacts下载。下载需要GitHub登录。
6. 如需复算，解压artifact，以其中research目录和pip-freeze环境、experiment-out/dataset.json重跑train_five_day.py到一个新的输出目录；不需要再下载历史行情。不要加载来源不明的joblib。

本轮不会把训练候选自动接入网页。任何后续最终测试都必须先另行冻结策略、执行规则和数据；不能反复查看2026再挑冠军。
